# ViceBase Fan Hub

Build a simple MVP for an unofficial GTA VI fan website called ViceBase.

Use Next.js, TypeScript, and Tailwind CSS.

The goal is a fast, modern, SEO-friendly content website that can eventually earn revenue from ads.

Architecture

Keep the code simple and reusable so I can easily add many more character, feature, news, and guide pages later.

Use local/static data only. No database, authentication, payments, or backend.

Add simple placeholders for future advertisements without implementing an ad network.

Make it look like a real gaming information website, not a generic template.

Clearly state that ViceBase is an unofficial fan website and is not affiliated with Rockstar Games or Take-Two Interactive.
